# Verbete — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Verbete, a static Brazilian-Portuguese word-guessing game with three board variants (Solo/Dueto/Quarteto), each playable in a deterministic daily mode and an unlimited infinite mode, that reveals the word's dictionary definition at the end of every match.

**Architecture:** A pure TypeScript game engine with zero DOM/React/storage dependencies, consumed by a thin React UI. Word data is generated at build time from open-licensed sources and committed. Everything ships as static files served by nginx; no backend, no database, no Node process in production.

**Tech Stack:** Vite · React 19 · TypeScript strict · Tailwind CSS · Vitest · Playwright · vite-plugin-pwa · pnpm · Node 20

**Spec:** `docs/superpowers/specs/2026-09-20-verbete-design.md`

## Global Constraints

- **Node 20**, pinned in `.nvmrc` and `engines`. **pnpm** pinned via `packageManager` in `package.json`.
- **TypeScript strict** plus `noUncheckedIndexedAccess`. Every indexed access needs a non-null assertion or a guard.
- **`src/engine/**` may import only from `src/engine/**`.** No React, no DOM, no `localStorage`, no `navigator`, no `Date.now()`, no `Math.random()`. Enforced by ESLint and by an architecture test.
- **Word length is 5.** Attempts: Solo 6, Dueto 7, Quarteto 9.
- **Timezone is `America/Sao_Paulo`**, always via `Intl`. Never hardcode `-03:00`.
- **Normalization has two directions and they are not interchangeable:** NFC to measure length and store display forms; NFD-plus-strip-combining-marks to build comparison keys.
- **Guess input is `A-Z` only.** No `Ç`, no accents. Diacritics are never a hint.
- **Answers are dictionary head-forms only** — noun, adjective, adverb or infinitive verb. Conjugations and plurals stay valid as guesses, never as answers.
- **Tailwind classes must be written out in full.** Never build a class name by interpolation — Tailwind's scanner will prune it.
- **Portuguese in the UI, English in the code.** Identifiers, comments and commit messages in English; every user-facing string in pt-BR.
- **Licensing:** generated word lists carry an MPL-1.1 header crediting VERO; the definitions file carries a CC BY-SA 4.0 header crediting Wikcionário. An "About" screen must reproduce both attributions.
- **Commit after every task.** Conventional Commits (`feat:`, `test:`, `chore:`, `fix:`).

const COMBINING_MARKS = /[̀-ͯ]/g;

/**
 * Comparison key: NFD decomposes every diacritic — including the cedilla,
 * which becomes "c" + U+0327 — so one pass strips them all.
 * Use this for anything the game compares. Never for anything it displays.
 */
export function normalize(input: string): string {
  return input.normalize('NFD').replace(COMBINING_MARKS, '').toUpperCase();
}

/**
 * Display/measurement form. Sources and filesystems hand us NFD, where
 * "maçã".length is 6. Recompose before counting letters or storing a word.
 */
export function toNfc(input: string): string {
  return input.normalize('NFC');
}

export function isTypeable(value: string, length: number): boolean {
  return value.length === length && /^[A-Z]+$/.test(value);
}
```

import type { Tile } from './types';

/**
 * Two passes, and the order matters. Pass one claims exact positions and
 * counts what the answer has left over. Pass two spends that budget on
 * misplaced letters, left to right. Doing it in one pass over-credits
 * repeated letters: ERRAR against TERRA would mark all three R.
 *
 * Both arguments must already be normalized and the same length.
 */
export function scoreGuess(guess: string, answer: string): readonly Tile[] {
  const size = guess.length;
  const tiles: Tile[] = new Array<Tile>(size).fill('absent');
  const unmatched = new Map<string, number>();

  for (let i = 0; i < size; i += 1) {
    const letter = guess[i]!;
    const target = answer[i]!;
    if (letter === target) {
      tiles[i] = 'correct';
    } else {
      unmatched.set(target, (unmatched.get(target) ?? 0) + 1);
    }
  }

  for (let i = 0; i < size; i += 1) {
    if (tiles[i] === 'correct') continue;
    const letter = guess[i]!;
    const available = unmatched.get(letter) ?? 0;
    if (available > 0) {
      tiles[i] = 'present';
      unmatched.set(letter, available - 1);
    }
  }

  return tiles;
}
```

```ts
/**
 * Every operation here goes through Math.imul and >>> 0. That is what keeps
 * the arithmetic in 32-bit unsigned space and makes the output byte-identical
 * across V8, JavaScriptCore and SpiderMonkey. Plain * and + would overflow
 * into float64 and drift between engines — and a daily word that differs by
 * browser is the whole feature broken.
 */
export function hashSeed(seed: string): number {
  let h = 1779033703 ^ seed.length;
  for (let i = 0; i < seed.length; i += 1) {
    h = Math.imul(h ^ seed.charCodeAt(i), 3432918353);
    h = (h << 13) | (h >>> 19);
  }
  h = Math.imul(h ^ (h >>> 16), 2246822507);
  h = Math.imul(h ^ (h >>> 13), 3266489909);
  return (h ^= h >>> 16) >>> 0;
}

export function mulberry32(seed: number): () => number {
  let state = seed >>> 0;
  return () => {
    state = (state + 0x6d2b79f5) >>> 0;
    let t = state;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/** Fisher-Yates over a copy. */
export function shuffled<T>(items: readonly T[], rand: () => number): T[] {
  const out = [...items];
  for (let i = out.length - 1; i > 0; i -= 1) {
    const j = Math.floor(rand() * (i + 1));
    const a = out[i]!;
    const b = out[j]!;
    out[i] = b;
    out[j] = a;
  }
  return out;
}

export interface Clock {
  now(): number;
}

const MS_PER_DAY = 86_400_000;

// "en-CA" formats as YYYY-MM-DD, which saves reassembling the parts by hand.
const DAY_FORMAT = new Intl.DateTimeFormat('en-CA', {
  timeZone: TIME_ZONE,
  year: 'numeric',
  month: '2-digit',
  day: '2-digit',
});

export function dayKeyOf(nowMs: number): string {
  return DAY_FORMAT.format(nowMs);
}

/**
 * Days since EPOCH_DAY_KEY. Parsing the key as UTC midnight is safe precisely
 * because the key already carries the Sao Paulo calendar date — we are doing
 * calendar arithmetic, not instant arithmetic, so no offset applies.
 */
export function epochDayOf(dayKey: string): number {
  return Math.round((asUtcMidnight(dayKey) - asUtcMidnight(EPOCH_DAY_KEY)) / MS_PER_DAY);
}

export function msUntilNextMidnight(nowMs: number): number {
  const tomorrow = dayKeyFromEpochDay(epochDayOf(dayKeyOf(nowMs)) + 1);
  // Walk minute by minute from a safe lower bound rather than assuming a fixed
  // UTC offset: Brazil dropped DST in 2019, but that is a political decision
  // and Intl tracks the tzdata, so never hardcode -03:00.
  let probe = nowMs + MS_PER_DAY - 6 * 60 * 60 * 1000;
  while (dayKeyOf(probe) !== tomorrow) probe += 60_000;
  while (dayKeyOf(probe - 1000) !== tomorrow) probe -= 1000;
  return probe - nowMs;
}

export function areConsecutive(earlier: string, later: string): boolean {
  return epochDayOf(later) - epochDayOf(earlier) === 1;
}

export function dayKeyFromEpochDay(day: number): string {
  const ms = asUtcMidnight(EPOCH_DAY_KEY) + day * MS_PER_DAY;
  return new Date(ms).toISOString().slice(0, 10);
}

function asUtcMidnight(dayKey: string): number {
  const [year, month, day] = dayKey.split('-').map(Number) as [number, number, number];
  return Date.UTC(year, month - 1, day);
}
```

```ts
const ALPHABET_SIZE = 26;
const CODE_A = 65;
const WORD_LENGTH = 5;

/** Base-26 integer. 26^5 is 11,881,376 — comfortably inside 24 bits. */
export function encodeWord(word: string): number {
  let value = 0;
  for (let i = 0; i < WORD_LENGTH; i += 1) {
    value = value * ALPHABET_SIZE + (word.charCodeAt(i) - CODE_A);
  }
  return value;
}

export function decodeWord(value: number): string {
  const letters = new Array<string>(WORD_LENGTH);
  let rest = value;
  for (let i = WORD_LENGTH - 1; i >= 0; i -= 1) {
    letters[i] = String.fromCharCode(CODE_A + (rest % ALPHABET_SIZE));
    rest = Math.floor(rest / ALPHABET_SIZE);
  }
  return letters.join('');
}

/**
 * Sorted integers stored as gaps, each gap as LEB128, the byte stream as
 * base64. Gaps between neighbours in a dense sorted list are small, so most
 * take one or two bytes — which is why this lands near 13 KB gzipped for
 * ten thousand words where a JSON array takes 28 KB.
 */
export function packSortedWords(sortedWords: readonly string[]): string {
  const bytes: number[] = [];
  let previous = 0;
  for (const word of sortedWords) {
    let delta = encodeWord(word) - previous;
    previous += delta;
    while (delta >= 0x80) {
      bytes.push((delta & 0x7f) | 0x80);
      delta >>>= 7;
    }
    bytes.push(delta);
  }
  let binary = '';
  for (const byte of bytes) binary += String.fromCharCode(byte);
  return btoa(binary);
}

export function unpackWords(base64: string, count: number): Int32Array {
  const binary = atob(base64);
  const table = new Int32Array(count);
  let cursor = 0;
  let value = 0;
  for (let index = 0; index < count; index += 1) {
    let delta = 0;
    let shift = 0;
    for (;;) {
      const byte = binary.charCodeAt(cursor);
      cursor += 1;
      delta |= (byte & 0x7f) << shift;
      if ((byte & 0x80) === 0) break;
      shift += 7;
    }
    value += delta;
    table[index] = value;
  }
  return table;
}

export function containsWord(table: Int32Array, word: string): boolean {
  const target = encodeWord(word);
  let low = 0;
  let high = table.length - 1;
  while (low <= high) {
    const mid = (low + high) >>> 1;
    const value = table[mid]!;
    if (value === target) return true;
    if (value < target) low = mid + 1;
    else high = mid - 1;
  }
  return false;
}
```

function assertBuildInvariants(guesses: string[], answers: string[]): void {
  const guessSet = new Set(guesses);

  for (const answer of answers) {
    const key = normalize(answer);
    if (!guessSet.has(key)) {
      throw new Error(`answer "${answer}" is not an accepted guess — unplayable`);
    }
    if (!/^[A-Z]{5}$/.test(key)) {
      throw new Error(`answer "${answer}" does not normalize to five letters`);
    }
  }

  const seen = new Map<string, string>();
  for (const answer of answers) {
    const key = normalize(answer);
    const clash = seen.get(key);
    if (clash) {
      throw new Error(
        `answers "${clash}" and "${answer}" share the key ${key}: the player ` +
        `would type it, win, and be shown the other word`,
      );
    }
    seen.set(key, answer);
  }

  if (answers.length < DAILY_POOL_SIZE) {
    throw new Error(`need at least ${DAILY_POOL_SIZE} answers, got ${answers.length}`);
  }
}

import { containsWord, unpackWords } from './codec';
import { GUESSES_B64, GUESSES_COUNT } from './guesses.generated';
import { ANSWERS } from './answers.generated';
import { DAILY_POOL_SIZE } from '../engine/constants';

let table: Int32Array | null = null;

function lookupTable(): Int32Array {
  // Decoded once, lazily: about 1 ms and 40 KB of Int32Array, against the
  // ~1 MB a Set of ten thousand strings would hold.
  table ??= unpackWords(GUESSES_B64, GUESSES_COUNT);
  return table;
}

export function isValidGuess(normalized: string): boolean {
  return containsWord(lookupTable(), normalized);
}

export function answerPool(): readonly string[] {
  return ANSWERS;
}

/**
 * The daily deck permutes indices 0..DAILY_POOL_SIZE-1, so its output depends
 * on the pool's exact size. Slicing to a frozen constant means later additions
 * to ANSWERS extend infinite mode without renumbering every future daily word.
 * See Risk 2 in the spec. Do not make this dynamic.
 */
export function dailyPool(): readonly string[] {
  return ANSWERS.slice(0, DAILY_POOL_SIZE);
}

export function pickRandomAnswer(
  exclude: ReadonlySet<string>,
  rand: () => number,
): string {
  const pool = ANSWERS;
  for (let attempt = 0; attempt < 100; attempt += 1) {
    const candidate = pool[Math.floor(rand() * pool.length)]!;
    if (!exclude.has(candidate)) return candidate;
  }
  // Exhausted the sampling budget: the exclusion list has grown too dense.
  const open = pool.filter((word) => !exclude.has(word));
  return (open.length > 0 ? open : pool)[Math.floor(rand() * Math.max(open.length, 1))] ?? pool[0]!;
}

import { VARIANTS, WORD_LENGTH } from './constants';
import { normalize } from './normalize';
import { scoreGuess } from './score';
import type { MatchStatus, Mode, Tile, Variant } from './types';

export interface BoardState {
  readonly answer: string;
  readonly answerNorm: string;
  readonly solvedAt: number | null;
}

export interface MatchState {
  readonly variant: Variant;
  readonly mode: Mode;
  readonly dayKey: string | null;
  readonly boards: readonly BoardState[];
  readonly guesses: readonly string[];
  readonly draft: string;
  readonly status: MatchStatus;
  readonly maxAttempts: number;
  readonly startedAt: number;
  readonly finishedAt: number | null;
}

export interface Row {
  readonly guess: string;
  readonly tiles: readonly Tile[];
}

export type Action =
  | { type: 'TYPE'; letter: string }
  | { type: 'BACKSPACE' }
  | { type: 'SUBMIT' };

export type InvalidReason = 'too_short' | 'not_in_dictionary' | 'already_guessed';

export type Effect =
  | { type: 'REJECTED'; reason: InvalidReason; word: string }
  | { type: 'ACCEPTED'; guessIndex: number }
  | { type: 'BOARD_SOLVED'; boardIndex: number; guessIndex: number }
  | { type: 'FINISHED'; status: 'won' | 'lost' };

export interface EngineDeps {
  isValidGuess: (normalized: string) => boolean;
  now: () => number;
}

export interface Transition {
  readonly state: MatchState;
  readonly effects: readonly Effect[];
}

export interface MatchInit {
  variant: Variant;
  mode: Mode;
  dayKey: string | null;
  answers: readonly string[];
  startedAt: number;
}

export function createMatch(init: MatchInit): MatchState {
  return {
    variant: init.variant,
    mode: init.mode,
    dayKey: init.dayKey,
    boards: init.answers.map((answer) => ({
      answer,
      answerNorm: normalize(answer),
      solvedAt: null,
    })),
    guesses: [],
    draft: '',
    status: 'playing',
    maxAttempts: VARIANTS[init.variant].attempts,
    startedAt: init.startedAt,
    finishedAt: null,
  };
}

export function remainingAttempts(state: MatchState): number {
  return state.maxAttempts - state.guesses.length;
}

/**
 * Rows are derived, never stored. A board that was solved at guess k stops
 * producing rows after k, which is how "solved boards freeze" falls out with
 * no branch of its own.
 */
export function boardRows(state: MatchState, boardIndex: number): readonly Row[] {
  const board = state.boards[boardIndex]!;
  const limit = board.solvedAt !== null ? board.solvedAt + 1 : state.guesses.length;
  return state.guesses.slice(0, limit).map((guess) => ({
    guess,
    tiles: scoreGuess(guess, board.answerNorm),
  }));
}

export function reduce(state: MatchState, action: Action, deps: EngineDeps): Transition {
  if (state.status !== 'playing') return { state, effects: [] };

  switch (action.type) {
    case 'TYPE': {
      if (state.draft.length >= WORD_LENGTH) return { state, effects: [] };
      return { state: { ...state, draft: state.draft + action.letter }, effects: [] };
    }
    case 'BACKSPACE': {
      if (state.draft.length === 0) return { state, effects: [] };
      return { state: { ...state, draft: state.draft.slice(0, -1) }, effects: [] };
    }
    case 'SUBMIT':
      return submit(state, deps);
  }
}

function submit(state: MatchState, deps: EngineDeps): Transition {
  const word = state.draft;

  // Every rejection returns the SAME state object, so a wrong guess costs no
  // attempt and callers can assert identity rather than deep-compare.
  if (word.length !== WORD_LENGTH) {
    return { state, effects: [{ type: 'REJECTED', reason: 'too_short', word }] };
  }
  if (state.guesses.includes(word)) {
    return { state, effects: [{ type: 'REJECTED', reason: 'already_guessed', word }] };
  }
  if (!deps.isValidGuess(word)) {
    return { state, effects: [{ type: 'REJECTED', reason: 'not_in_dictionary', word }] };
  }

  const guessIndex = state.guesses.length;
  const effects: Effect[] = [{ type: 'ACCEPTED', guessIndex }];

  const boards = state.boards.map((board, boardIndex) => {
    if (board.solvedAt !== null || board.answerNorm !== word) return board;
    effects.push({ type: 'BOARD_SOLVED', boardIndex, guessIndex });
    return { ...board, solvedAt: guessIndex };
  });

  const guesses = [...state.guesses, word];
  const allSolved = boards.every((board) => board.solvedAt !== null);
  const outOfAttempts = guesses.length >= state.maxAttempts;
  const status: MatchStatus = allSolved ? 'won' : outOfAttempts ? 'lost' : 'playing';
  if (status !== 'playing') effects.push({ type: 'FINISHED', status });

  return {
    state: {
      ...state,
      boards,
      guesses,
      draft: '',
      status,
      finishedAt: status === 'playing' ? null : deps.now(),
    },
    effects,
  };
}

import { boardRows } from './match';
import type { MatchState } from './match';
import type { Tile } from './types';

export type KeyState = Tile | 'unused';

/** No cedilla and no accented keys: input is A-Z, diacritics are never hints. */
export const KEY_ROWS: readonly (readonly string[])[] = [
  ['Q', 'W', 'E', 'R', 'T', 'Y', 'U', 'I', 'O', 'P'],
  ['A', 'S', 'D', 'F', 'G', 'H', 'J', 'K', 'L'],
  ['Z', 'X', 'C', 'V', 'B', 'N', 'M'],
];

const RANK: Record<KeyState, number> = { unused: 0, absent: 1, present: 2, correct: 3 };

export function keyboardStates(state: MatchState): ReadonlyMap<string, readonly KeyState[]> {
  const boardCount = state.boards.length;
  const result = new Map<string, KeyState[]>();
  for (const letter of KEY_ROWS.flat()) {
    result.set(letter, new Array<KeyState>(boardCount).fill('unused'));
  }

  for (let boardIndex = 0; boardIndex < boardCount; boardIndex += 1) {
    for (const row of boardRows(state, boardIndex)) {
      row.tiles.forEach((tile, position) => {
        const letter = row.guess[position]!;
        const states = result.get(letter);
        if (!states) return;
        // Monotonic: a letter only ever climbs. Otherwise a later guess in a
        // different position would demote a confirmed green back to grey.
        if (RANK[tile] > RANK[states[boardIndex]!]) states[boardIndex] = tile;
      });
    }
  }

  return result;
}

import { epochDayOf } from './clock';
import { VARIANTS } from './constants';
import { hashSeed, mulberry32, shuffled } from './rng';
import type { Variant } from './types';

const SALT = 'verbete.devduraes.com.br/v1';

/** 1 solo + 2 dueto + 4 quarteto. */
const SLOTS_PER_DAY = 7;

/**
 * Where each variant reads inside the day's seven slots.
 * APPEND-ONLY. Inserting a variant in the middle shifts every later variant's
 * whole future history. A new variant takes the next free offset and
 * SLOTS_PER_DAY grows; the existing numbers never move.
 */
const SLOT_OFFSET: Record<Variant, number> = { solo: 0, dueto: 1, quarteto: 3 };

const permutations = new Map<number, readonly number[]>();

function permutationFor(cycle: number, poolSize: number): readonly number[] {
  // Memoized: without this, each of the seven daily lookups reshuffles 1500
  // elements from scratch.
  let cached = permutations.get(cycle);
  if (!cached) {
    const indices = Array.from({ length: poolSize }, (_, i) => i);
    cached = shuffled(indices, mulberry32(hashSeed(`${SALT}|cycle|${cycle}`)));
    permutations.set(cycle, cached);
  }
  return cached;
}

function drawAt(cursor: number, poolSize: number): number {
  const cycle = Math.floor(cursor / poolSize);
  const position = cursor % poolSize;
  return permutationFor(cycle, poolSize)[position]!;
}

export function dailyAnswers(
  dayKey: string,
  variant: Variant,
  pool: readonly string[],
): readonly string[] {
  const day = epochDayOf(dayKey);
  const base = day * SLOTS_PER_DAY;

  // Draw all seven of the day's slots from one stream, deduplicating as we go:
  // at a cycle boundary the last word of cycle c can reappear early in c+1.
  // Deduplicating across the whole day is what guarantees that no two boards —
  // in the same variant or across variants — share a word today.
  const daily: string[] = [];
  const taken = new Set<string>();
  for (let cursor = base; daily.length < SLOTS_PER_DAY; cursor += 1) {
    const word = pool[drawAt(cursor, pool.length)]!;
    if (taken.has(word)) continue;
    taken.add(word);
    daily.push(word);
  }

  const offset = SLOT_OFFSET[variant];
  return daily.slice(offset, offset + VARIANTS[variant].boards);
}

export function dailyNumber(dayKey: string): number {
  return epochDayOf(dayKey) + 1;
}

import { areConsecutive } from './clock';
import type { Mode } from './types';

export interface StatsRecord {
  readonly played: number;
  readonly wins: number;
  readonly streak: number;
  readonly bestStreak: number;
  readonly lastWinDayKey: string | null;
  readonly distribution: Readonly<Record<number, number>>;
}

export interface MatchResult {
  readonly won: boolean;
  readonly attempts: number | null;
  readonly dayKey: string | null;
  readonly mode: Mode;
}

export function emptyStats(): StatsRecord {
  return {
    played: 0, wins: 0, streak: 0, bestStreak: 0,
    lastWinDayKey: null, distribution: {},
  };
}

export function applyResult(previous: StatsRecord, result: MatchResult): StatsRecord {
  const distribution = { ...previous.distribution };
  if (result.won && result.attempts !== null) {
    distribution[result.attempts] = (distribution[result.attempts] ?? 0) + 1;
  }

  const base = {
    played: previous.played + 1,
    wins: previous.wins + (result.won ? 1 : 0),
    distribution,
  };

  // Streaks belong to the daily challenge. Infinite mode counts towards games
  // and wins but must never advance or break a streak.
  if (result.mode !== 'diario' || result.dayKey === null) {
    return { ...previous, ...base };
  }

  if (!result.won) {
    return { ...previous, ...base, streak: 0 };
  }

  const continues =
    previous.lastWinDayKey !== null && areConsecutive(previous.lastWinDayKey, result.dayKey);
  const streak = continues ? previous.streak + 1 : 1;

  return {
    ...previous,
    ...base,
    streak,
    bestStreak: Math.max(previous.bestStreak, streak),
    lastWinDayKey: result.dayKey,
  };
}

export function winRate(stats: StatsRecord): number {
  return stats.played === 0 ? 0 : Math.round((stats.wins / stats.played) * 100);
}

  const title = state.dayKey
    ? `Verbete ${VARIANT_LABEL[state.variant]} #${dailyNumber(state.dayKey)} — ${score}`
    : `Verbete ${VARIANT_LABEL[state.variant]} (infinito) — ${score}`;

  const lines: string[] = [title, ''];

  for (let guessIndex = 0; guessIndex < state.guesses.length; guessIndex += 1) {
    const segments = state.boards.map((board, boardIndex) => {
      const rows = boardRows(state, boardIndex);
      const row = rows[guessIndex];
      // A board solved earlier produces no row here; emit blanks so the
      // columns of a dueto/quarteto grid stay aligned.
      if (!row) return BLANK.repeat(WORD_LENGTH);
      return row.tiles.map((tile) => GLYPH[tile]).join('');
    });
    lines.push(segments.join(' '));
  }

  lines.push('', options.url);
  return lines.join('\n');
}
```

  // one definition per match, and only at the end. The service worker
  // precaches this chunk so offline play still gets it.
  cache ??= (await import('./definitions.generated.json')).default as Record<string, string>;
  return cache[word] ?? null;
}
```

- [ ] **Step 4: Show it in the result modal**

`ResultModal.tsx` presents the finished match as a dictionary entry: the accented word as the headword, `s.m.` or the matching part-of-speech abbreviation, the definition, and a link to `https://pt.wiktionary.org/wiki/<word>` — which is also the most robust way to satisfy the CC BY-SA attribution. Show it on a loss as well as a win.

## Task 26: VPS provisioning

Every script here is idempotent and **run by Guilherme**, not by the agent: SSH writes are blocked in auto mode. Prepare each one, then ask him to run `! bash deploy/vps/<script>.sh`.

**Files:**
- Create: `deploy/vps/01-dns.sh`, `deploy/vps/02-certificate.sh`, `deploy/vps/03-layout.sh`, `deploy/vps/04-nginx.sh`, `deploy/vps/05-deploy-key.sh`, `deploy/vps/deploy-wrapper.sh`, `deploy/nginx/verbete`, `deploy/README.md`

- [ ] **Step 1: DNS**

Create `verbete.devduraes.com.br` as a CNAME to the apex, **proxied**. This is not optional: the VPS firewall only opens 80/443 to Cloudflare's ranges, so a grey-cloud record means an unreachable site.

- [ ] **Step 2: Expand the certificate to a wildcard**

The `devduraes.com.br` lineage currently covers only the apex and `www`.

```bash
sudo certbot certonly --dns-cloudflare \
  --dns-cloudflare-credentials /root/.secrets/cloudflare-devduraes.ini \
  --dns-cloudflare-propagation-seconds 30 \
  --key-type ecdsa --cert-name devduraes.com.br \
  -d devduraes.com.br -d www.devduraes.com.br -d '*.devduraes.com.br'
```

> **Wrong, corrected 2026-09-23.** `-d www.devduraes.com.br` must not be there:
> Let's Encrypt rejects a request carrying both the www and the wildcard
> ("redundant with a wildcard domain in the same request"). The `--ensaio` dry
> run in `deploy/vps/02-certificate.sh` caught it before the live certificate
> was touched. Drop the `-d www.` and the command works; the wildcard covers
> www and the apex stays explicit, so coverage is unchanged. Use the script.

Confirm `/etc/letsencrypt/renewal-hooks/deploy/reload-nginx.sh` exists and is executable. `certbot renew --dry-run` does **not** run deploy hooks, so test it by invoking the script directly with `RENEWED_LINEAGE` set.

- [ ] **Step 3: Create the layout**

`/srv/verbete/app` owned `qyro:qyro` for the served files, and `/srv/verbete/bin/deploy-wrapper.sh` owned by root at mode 755.

- [ ] **Step 4: Write the vhost**

`deploy/nginx/verbete`, modelled on the nossario vhost:

- **Only `listen 443 ssl http2`.** No port-80 block — the 301 comes from the qyro catch-all, and a second `default_server` breaks `nginx -t`. No `default_server` on 443 either; that belongs to amgseg.
- A `verbete` `log_format` carrying `$http_cf_connecting_ip`, since behind Cloudflare `$remote_addr` is always the edge.
- HSTS, `X-Frame-Options DENY`, `nosniff` and `Referrer-Policy`, each with `always`.
- `index.html`, `sw.js` and `manifest.webmanifest` → `Cache-Control: no-store, must-revalidate`. `/assets/*`, whose names carry Vite's content hash → `expires 1y` and `public, immutable`.
- `try_files $uri $uri/ /index.html;`

Install it, then `sudo nginx -t` **before** `systemctl reload nginx`. Reload, never restart: a syntax error takes all five sites down at once.

- [ ] **Step 5: Create the restricted deploy key**

Generate `~/.ssh/verbete_deploy` and pin it in the VPS `authorized_keys`:

```
restrict,command="/srv/verbete/bin/deploy-wrapper.sh" ssh-ed25519 AAAA... verbete_deploy
```

`deploy-wrapper.sh` follows the RPG model: `set -f`, `set -- $SSH_ORIGINAL_COMMAND`, `exec "$@"` — never `sh -c`. It accepts only `rsync --server`, **refuses `--sender`** (a read-direction rsync would pull the other projects' `.env` files off the shared machine), refuses any destination containing `..`, and matches the single permitted destination **exactly** rather than by prefix — a `/srv/verbete/*` prefix would let a deploy overwrite the wrapper itself. It fails closed. This machine has already been lost once to an unrestricted deploy key.

- [ ] **Step 6: Verify, including the neighbours**

```bash

for d in qyrofinance.com.br amgseg.com.br nossario.com.br devduraes.com.br; do
  echo -n "$d "; curl -sI "https://$d" | head -1
done
sudo certbot certificates | grep -A1 devduraes
```

All five must answer. Touching nginx on a shared box is the real risk in this task.
